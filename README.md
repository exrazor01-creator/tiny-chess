A 4 KB Python chess engine: a 0x88 board, negamax alpha-beta search with quiescence, a transposition table, killer moves, late-move reductions and an incremental material plus piece-square evaluation, playing the house gauntlet through the make.fun env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
